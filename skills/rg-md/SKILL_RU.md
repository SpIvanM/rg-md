# Поиск по кодовой базе с помощью rg-md

Цель: минимизировать число шагов агента, объем контекста и затраты на поиск с помощью rg-md.

## Директивы выполнения
- Запускайте rg-md или md-rg напрямую без предварительных проверок окружения.
- ‼ При вызове rg-md или md-rg проверка наличия утилиты через --version или --help строго запрещена.
- Если утилита rg-md не найдена в системе, см. [installation.ru.md](./references/installation.ru.md).
- Запускайте rg-md "<шаблон>" [путь] [опции ripgrep...] для структурированного поиска.
- Немедленно переходите к точечному вызову read_file после обнаружения нужных файлов и номеров строк.
- Указывайте конкретный подкаталог поиска вместо корня проекта при поиске доменных идентификаторов.
- Передавайте стандартные флаги ripgrep напрямую: -t для типов файлов, -i для поиска без учета регистра, -w для точных слов.
- Завершайте фазу исследования сразу после определения целевых файлов и сигнатур.
- ‼ При исследовании кодовой базы чтение файлов целиком через read_file строго запрещено.
- ‼ При поиске идентификаторов слепой рекурсивный поиск без ограничения пути строго запрещен.
- Ограничивайте read_file небольшими диапазонами строк (до 50 строк), найденными через rg-md.
