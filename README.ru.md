## Общие сведения

rg-md — это высокопроизводительная консольная утилита поиска на Rust, форматирующая результаты поиска ripgrep в структурированный Markdown.

Стандартные ИИ-агенты кодинга используют ripgrep или grep при исследовании кодовой базы. Необработанный вывод grep форматирует совпадения с префиксами через двоеточие (`путь:строка:содержимое`), что провоцирует ошибки объединения строк токенизаторами LLM, переполняет буферы вывода инструментов и раздувает контекст промптов.

rg-md запускает ripgrep и преобразует группы файлов в заголовки Markdown (`### `) со списками совпадений с номерами строк (`  - L<номер>: <строка>`). Эта структурная иерархия превращает текстовые совпадения в древовидный документ, который языковые модели разбирают без потери контекста и лишних накладных расходов.

```
       ┌────────────────────────────────────────────────────────┐
       │   Шаг агента:  rg-md "RecordingOverlay" src/           │
       └──────────────────────────┬─────────────────────────────┘
                                  ▼
 ┌──────────────────────────────────────────────────────────────┐
 │               Структурированный вывод rg-md                  │
 │                                                              │
 │  ### `src/overlay/main.tsx`                                  │
 │    - L4: import RecordingOverlay from "./RecordingOverlay";  │
 │    - L23: <RecordingOverlay />                               │
 │                                                              │
 │  ### `src/overlay/RecordingOverlay.tsx`                      │
 │    - L4: import "./RecordingOverlay.css";                    │
 │    - L28: const RecordingOverlay: React.FC = () => {         │
 │    - L369: export default RecordingOverlay;                  │
 └──────────────────────────────────────────────────────────────┘
```

## Архитектурные преимущества для автономных агентов

### Экономия токенов за счет иерархии
Группировка совпадений под заголовками файлов устраняет дублирование полных путей к файлам на каждой строке. В бенчмарках это сокращает итоговый размер контекста сессии на 18.9% по сравнению со стандартным ripgrep и на 69.3% по сравнению с тяжелыми AST-навигаторами.

### Сокращение шагов агента
Благодаря однозначной структуре Markdown-списков модель быстрее локализует целевые участки кода. Исследовательские циклы автономного агента завершаются за 39 шагов против 54 шагов у ripgrep и 49 шагов у базового агента без инструментов навигации.

### Минимальное время выполнения
Реализация на Rust вносит менее 5 миллисекунд накладных расходов потокового форматирования поверх выполнения ripgrep.

### Прозрачная передача флагов ripgrep
Все стандартные аргументы ripgrep передаются напрямую. Агенты могут использовать фильтры путей (`-g "*.rs"`), селекторы типов (`-t ts`), флаги регистра (`-i`) или многострочный поиск без ограничений.

### Выводы бенчмарка

## Установка и распространение

Готовые исполняемые файлы собраны для Linux и Windows.

### Linux и macOS (команда для терминала)
Выполните в терминале:
```bash
curl -fsSL https://raw.githubusercontent.com/SpIvanM/rg-md/main/scripts/install.sh | bash
```
Скрипт устанавливает бинарник `rg-md` и символическую ссылку `md-rg` в `~/.local/bin/` и настраивает PATH.

### Windows (команда для PowerShell)
Выполните в PowerShell:
```powershell
irm https://raw.githubusercontent.com/SpIvanM/rg-md/main/scripts/install.ps1 | iex
```
Скрипт загружает `rg-md.exe` в `%LOCALAPPDATA%\Programs\rg-md\bin` и регистрирует PATH пользователя.

### Сборка из исходников через Cargo
```bash
cargo install --git https://github.com/SpIvanM/rg-md.git
```

## Интеграция с агентами

Для использования rg-md автономными агентами добавьте файл навыка и правила навигации в конфигурацию агента.

### Развертывание навыка (Skill)
Файл навыка расположен по пути `skills/rg-md/SKILL.md`.

Для Google Antigravity / AGY:
```bash
mkdir -p ~/.gemini/config/skills/rg-md
cp skills/rg-md/SKILL.md ~/.gemini/config/skills/rg-md/
```

Для Cursor:
Добавьте директивы из `skills/rg-md/SKILL.md` в `.cursor/rules/rg-md.mdc` или в `.cursorrules`.

Для Claude Code:
Добавьте блок директив в `CLAUDE.md`.

### Блок директив агента (AGENTS.md)
Добавьте этот блок в корневой `AGENTS.md` проекта или в общие правила агента:

```markdown
# >>> rg-md navigation rules >>>
## Codebase Navigation Directives
- Run rg-md "<pattern>" [path] [ripgrep-options...] for structured markdown search.
- Switch immediately to targeted read_file once relevant files and line numbers are located.
- ‼ If locating identifiers, blind recursive grep without path scope is strictly prohibited.
- ‼ If exploring codebase or symbols, reading whole files with read_file is strictly prohibited.
- Reserve read_file strictly for small line ranges (under 50 lines) pinpointed by search results.
# <<< rg-md navigation rules <<<
```

## Примеры использования

rg-md поддерживает позиционные аргументы и стандартные флаги поиска:

### Базовый поиск
```bash
# Поиск идентификатора по всей кодовой базе
rg-md "RecordingOverlay"

# Вызов через короткий псевдоним
md-rg "RecordingOverlay"
```

### Поиск с ограничением пути
```bash
# Поиск внутри конкретного каталога
rg-md "stop_recording" src-tauri/src
```

### Фильтрация по типам и опции
```bash
# Фильтрация по расширению файла
rg-md "handle_click" src/ -t tsx

# Поиск без учета регистра и по границам слов
rg-md -i -w "cancel_generation" src-tauri/
```
